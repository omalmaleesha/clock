## ✨ Features

| Feature | Description |
|--------|-------------|
| 🕐 **Real Local Time** | Always shows *your* accurate local time (HH:MM:SS) |
| 🌍 **Auto Location** | Detects your city & country automatically |
| 🎨 **3 Beautiful Themes** | Dark • Light • Night Blue Sky |
| 🖱️ **Silky Particle Trail** | Ultra-smooth mouse & touch trail effect |
| 📱 **Fully Responsive** | Looks great on mobile, tablet & desktop |
| 🖥️ **Landscape Mode** | One-tap fullscreen + landscape lock |
| 💾 **Theme Memory** | Remembers your preferred theme |
| ⚡ **Zero Dependencies** | Pure HTML, CSS & JavaScript |

---

## 🎨 Themes

| Dark | Light | Night Blue Sky |
|------|-------|----------------|
| Classic black with soft white glow | Clean light mode for daytime | Deep blue gradient + cyan neon digits |

Click the **theme button** (bottom-right) to cycle between them instantly.
